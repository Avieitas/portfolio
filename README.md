# Portfólio — Anauã Vieitas

Portfólio pessoal de estudante de Engenharia de Software na FIAP.

**Site:** https://anaua-vieitas.vercel.app

## Desenvolvimento local

Site estático em HTML, CSS e JavaScript, sem etapa de compilação.

Abra `index.html` no navegador ou execute:

```sh
python3 -m http.server 8080
```

## Publicação

O projeto está publicado na Vercel. A configuração está em `vercel.json`.

```sh
npx vercel --prod
```

## Conteúdo

- Apresentação e formação
- Projeto Barbearia
- Estudo de caso com telas recriadas e decisões técnicas
- Contato e redes profissionais

As animações respeitam a preferência de redução de movimento do dispositivo.
